One superchip, two processors.

GH200 Grace Hopper contains one Grace CPU SoC and one Hopper GPU joined by a coherent chip-to-chip connection. Grace CPU Superchip is a different two-Grace product; its white paper helps explain the Grace SoC inside GH200.

    SOURCE LIBRARY

    NVIDIA architecture references

    These NVIDIA documents establish the processor relationship and the parts represented in each schematic. Figure and page references appear again in the selected-part notes.

    GH200 / RELATIONSHIP
    NVIDIA Grace Hopper Superchip Architecture In-Depth ↗NVIDIA Technical Blog · Figure 2 · 2022

    One Grace CPU, one Hopper GPU, their separate attached memories, and coherent NVLink-C2C. The cited article gives 900 GB/s total, 450 GB/s per direction.

    GRACE / FABRIC
    NVIDIA Grace CPU Superchip Whitepaper ↗Version 1.1 · printed pp. 5–7, Table 1 and Figure 2

    Grace CPU cores, distributed cache, Cache Switch Nodes, Scalable Coherency Fabric, LPDDR5X, and system interfaces. Its headline 144-core and 228 MB L3 figures describe two Grace CPUs; this guide draws one.

    GRACE / MEMORY
    Inside NVIDIA Grace CPU ↗NVIDIA Technical Blog · LPDDR5X memory interface · 2022

    Describes the 32-channel Grace LPDDR5X interface and the path between the CPU fabric and attached memory. Capacity figures in this launch-era article are not used as fixed GH200 specifications here.

    HOPPER / FULL DIE
    NVIDIA H100 Tensor Core GPU Architecture ↗Version 1.04 · printed pp. 18–21, 47; Figure 6 (GH100) and Figure 7 (SM)

    Full GH100 hierarchy: GPCs, TPCs, SMs, L2, memory controllers, HBM, and fourth-generation NVLink. The white paper separately lists lower enabled counts for H100 products.

    GH200 / PRODUCT SCOPE
    NVIDIA Grace Performance Tuning Guide ↗NVIDIA documentation · product configuration tables

    Checks that GH200 has one Grace CPU and one Hopper GPU and distinguishes HBM3 and HBM3e variants. Capacity and enabled-unit counts vary by product.
