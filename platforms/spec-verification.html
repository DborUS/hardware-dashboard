What remains uncertain

  • This review verifies the changed claim groups and new profile evidence. It does not certify every old specification or every possible configured bill of materials.
  • HPE QuickSpecs are the primary configuration source. XD675 QuickSpecs and another HPE document conflict on memory channels/DPC, so those structured fields remain unknown; two CPUs and 24 slots are confirmed.
  • Cisco C225 M6 all-NVMe CPU requirements conflict within the specification; Lenovo ST650 has inconsistent one-CPU wording. Both limitations are visible on the affected profiles.
  • Some primary PDF content was checked through indexed OEM excerpts where direct retrieval failed. Review logs state these limits. Current orderability, software qualification and exact SKU combinations require separate verification.
  • The new and older installed-base placeholders have been redrawn from inspected official OEM references. The separate illustration review records the depicted configuration and any remaining schematic-only platforms.
