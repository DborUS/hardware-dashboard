Broad independent FAE audit: Dell and Lenovo
Date: 2026-10-09. Read-only audit of release 1.1.0; no application changes.

Coverage and limits
Inspected all 38 Dell/Lenovo catalog records (19 each), including CPU families, max sockets, documented installed CPU counts, memory slots/channels/DPC/type, GPU status/conditions, cooling, lifecycle, model/generation dates, source links and schema decoders. Opened current official product guides for all 19 Lenovo models and targeted processor/memory/cooling/GPU sections where risk or inconsistency existed. Dell external validation concentrated on 17G launch dates, R6715/R7715/R7725 memory, R7725 MI350P qualification and XE9785 MI355X/cooling. Other Dell rows were schema/consistency reviewed, not every option independently recertified. This is not an exhaustive SKU/configurator certification. Original artwork not altered; root handles browser review.

SD665's tray/node distinction is correct. No universal main memory-count inversion found.

Unresolved checks / do not report as proven errors
- R7725 thermal guide mentions single-processor fan counts, but other Dell public specs say two processors. Did not establish a supported one-CPU build strongly enough to flag Dell installedCPUCounts[2] as incorrect.
- AMD's solution-catalog PDF contains apparent inconsistencies for some Lenovo GPU model rows. Did not treat that alone as proof of a missing supported configuration; OEM model evidence should govern.
- No claim that current portfolio is exhaustive; no orderability,regional availability, firmware build or exact DIMM part-number certification performed.

Assessment
The improvements are substantive and the selected CPU/memory basics are generally reliable. Remaining risk is less about graphic polish and more about data completeness driving strict filters: a real supported option can disappear despite prose elsewhere admitting it exists. Fix that before calling the Finder a dependable shortlist tool. It is already a useful learning aid, with substantially better separation of CPU, GPU and lifecycle concepts.
